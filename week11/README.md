# MERN Post Management System

A full-stack blog application built with MongoDB, Express, React, and Node.js.

---

## Features

- Create, read, and delete posts
- Image upload with Cloudinary
- Real-time updates
- Loading states and error handling
- MongoDB Atlas integration
- Comprehensive test coverage

---

## Tech Used

HTML, CSS, JavaScript, React, Node.js, Express, MongoDB, Cloudinary, Vitest, Mocha

---

## How to Run

**Backend:**
```bash
cd backend
npm install
npm run dev
```
Backend runs on `http://localhost:5000`

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```
Frontend runs on `http://localhost:5173`

**Tests:**
```bash
# Frontend tests
cd frontend
npm test

# Backend tests
cd backend
npm test
```

> Note: Image upload requires internet connection and Cloudinary credentials.
